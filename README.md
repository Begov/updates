# BegoFrame

Настольная видео-студия для Windows: из готовой озвучки (аудио или видео) собирает готовый ролик.
Расшифровывает речь, режиссирует сцены через OpenAI Codex, подбирает сток,
генерирует картинки и видео нейросетями и склеивает финальный MP4 с переходами, логотипом и субтитрами.

Интерфейс на русском, английский включается одной кнопкой. У каждого параметра есть подсказка:
наведите на него курсор.

---

> Оформление: интерфейс построен на PySide6 и библиотеке PySide6-Fluent-Widgets (стиль Windows 11:
> боковая навигация, переключатели, тёмная и светлая темы). Библиотека распространяется под GPLv3 —
> для коммерческого распространения программы понадобится её коммерческая лицензия.

## 1. Что нужно

| Компонент | Зачем | Где взять |
|---|---|---|
| Windows 10/11 x64 | — | — |
| Python 3.11+ (проверено на 3.14) | запуск программы | python.org, при установке отметьте **Add to PATH** |
| FFmpeg (`ffmpeg` и `ffprobe` в PATH) | склейка видео | `winget install Gyan.FFmpeg` |
| Подписка ChatGPT (Plus/Pro/Business) | режиссура через Codex | chatgpt.com |
| Node.js 18+ (LTS, `node` и `npm` в PATH) | моушн-графика (Remotion) — только если она включена | nodejs.org или `winget install OpenJS.NodeJS.LTS` |
| Ключи сервисов | расшифровка, генерация и т. д. | см. раздел 4 |

Codex CLI отдельно ставить не нужно: программа скачает его сама («Настройки → Codex → Установить / обновить»).

## 2. Установка

**Обычный способ — установщик.** Скачайте `BegoFrame-Setup-<версия>.exe` со страницы
[выпусков](https://github.com/Begov/updates/releases/latest) и запустите. Права администратора не нужны;
по умолчанию программа ставится в `%LOCALAPPDATA%\Programs\BegoFrame` (папку можно сменить — проекты
с видео хранятся рядом с программой, поэтому выбирайте диск с запасом места). Python и библиотеки идут
в комплекте, отдельно ставится только FFmpeg (см. выше). Удаляется через «Параметры → Приложения»;
проекты, ключи и настройки при удалении остаются в папке программы.

**Обновления.** Программа сама проверяет новую версию при запуске (выключается в «Настройки →
Обновления», там же — проверка по кнопке). Если обновление есть, показывается, что изменилось;
«Скачать и установить» — программа закроется, обновится и запустится снова. Проекты, ключи (`.env`),
пресеты, журналы и изменённые вами промпты сохраняются; новые заводские версии получают только те
промпты, которые вы не меняли. Во время работы конвейера, стадий или склейки обновление не ставится.

**Из исходников (для разработки):**

1. Скопируйте папку `BegoFrame` в любое место, лучше без кириллицы в пути (например, `D:\BegoFrame`).
2. Запустите **`setup.bat`**. Он создаст окружение `.venv` и поставит зависимости из `requirements.txt`.

Если хотите поставить всё вручную:

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## 3. Запуск

- **`start.bat`** запускает программу без окна консоли;
- `python bego.py` запускает её с консолью (удобно для диагностики).

При первом запуске создаются папки `projects/`, `inbox/`, `runtime/`, `userdata/` и файл настроек `engine/.env`.

## 4. Первая настройка (вкладка «Настройки»)

1. **Codex:** «Установить / обновить», затем «Войти через браузер». Откроется окно входа OpenAI.
   После входа в строке состояния появятся почта аккаунта и квота подписки.
   - «Вход по коду» подходит для удалённых машин: код вводится на любом устройстве.
   - «Прокси Codex» нужен, если OpenAI недоступен из вашей сети. Впишите прокси в формате
     `схема://логин:пароль@host:port` (например `http://user:password@host:port` или `socks5://…`) и нажмите «Проверить».
2. **Ключи.** Заполните те, которыми будете пользоваться:
   - *AssemblyAI* — расшифровка речи (обязательно для старта «Из аудио»);
   - *FastGen / VeoNonStop / CinAI* — генерация картинок и видео;
   - *Vertex AI* — API-ключ и `PROJECT_ID` Google Cloud (картинки Banana и видео Veo);
   - *RoyalTechno* — ключ `rt_live_…` (выпускается в Telegram-боте командой `/api_key_new`): видео Veo 3.1, 720p, $0.02 за клип;
   - *VARAG* — ключ `mk_…` (Inflight API): картинки и видео; что доступно — решает тариф ключа;
   - *Pexels, Pixabay* — сток. Pexels работает и без ключа: впишите «Временный API-ключ» — строку
     из ссылки `pexels.com/_next/data/<ключ>/…` (сайт её иногда меняет). Если обычный ключ Pexels
     указан, поиск идёт через него.
   Для каждого сервиса указывается один ключ. Режиссура, переписывание промптов и vision-отбор
   стока идут через Codex (подписка ChatGPT), отдельные ключи для них не нужны.
3. **CinAI:** «Открыть cinai.tv», войдите на сайте, затем «Забрать сессию из браузера».
   Для картинок и ремиксера в программе доступны только бесплатные модели CinAI — безлимитные
   на тарифе (Banana Pro, Banana 2, Banana 2 Lite, Cin Lite Flash 1.1, CinGen Image 1.0, Seedream 5 Pro).
   Видео через CinAI — тоже только бесплатные модели (CinGen Video 1.0, Veo 3.1 Fast, Veo 3.1 Lite),
   720p, форматы 16:9 и 9:16.
   Потом сессия продлевается автоматически.
4. Нажмите **«Сохранить»** (Ctrl+S).

Ключи из прежней установки переносятся кнопкой «Импорт ключей из .env…»: подставятся только известные
параметры, и перед сохранением их можно проверить. Поиск слева ищет по названию, по ключу `.env` и по тексту подсказки.

## 5. Конвейер (вкладка «Конвейер»)

Главный режим: очередь файлов проходит все стадии без вашего участия.

1. **Очередь.** Перетащите в таблицу аудио или видео (mp3, wav, mp4…) либо нажмите «Добавить…».
   Каждому файлу через контекстное меню можно назначить свой стайлгайд, пресет, логотип и обложку.
   Кнопка «★ Запомнить настройки» закрепляет за файлом текущие настройки.
2. **Пресет.** Сохраните набор настроек под именем и переключайтесь между наборами. Пресеты можно экспортировать и импортировать.
3. **Точка старта:** *Из аудио* — готовая озвучка расшифровывается и монтируется.
   Рядом показывается квота GPT: окно 5 часов и неделя.
4. **Разделы** (каждый сворачивается, в заголовке видна краткая сводка):
   - *Транскрипция и режиссура* — режиссёр OpenAI (Codex), модель, клипы;
   - *Вступление* — отдельные правила для первых секунд ролика;
   - *Сток (видео + фото)* — Pexels, Pixabay, локальная библиотека;
   - *Инфографика* — статичные диаграммы на месте кадра; провайдеры и модели те же, что в «Генерации
     картинок», но выбираются отдельно;
   - *Моушн-графика* — анимированные вставки (счётчики, графики, карты, таймлайны). Где их ставить,
     решает режиссёр, сцену на React пишет Codex (модель выбирается в разделе), рендерит
     [Remotion](https://www.remotion.dev). Нужен Node.js; сам Remotion (~400 МБ) ставится кнопкой
     «Установить Remotion» или автоматически при первом запуске в `runtime/remotion`. Исходник каждой
     сцены сохраняется в `projects/<имя>/mograph/`. Не получилось — клип уходит в обычную нейрогенерацию.
     Лицензия Remotion бесплатна для частных лиц и компаний до 3 сотрудников, крупнее — нужна
     [Company License](https://www.remotion.dev/license);
   - *Генерация картинок* (FastGen / VeoNonStop / Vertex / CheapVibeCode / VARAG / CinAI), *Ремиксер*,
     *Генерация видео* (VeoNonStop / Vertex / RoyalTechno / VARAG / CinAI);
   - *Формат кадра* (16:9 / 9:16) — один на весь ролик: переключатель есть в картинках,
     инфографике, ремиксере и видео, меняется везде сразу. Каждая модель получает формат последней
     строкой промпта, а модели, которые понимают параметр формата, — ещё и в запросе;
   - *Состав видео* — ползунком делится 100 % клипов между сток-видео, сток-фото, инфографикой,
     моушн-графикой и нейрогенерацией (она получает остаток). Пока включена только нейрогенерация,
     раздел показывает её 100 %, а ползунок недоступен. Доли стока, инфографики и моушн-графики —
     предпочтение, а не квота: режиссёр (Codex) помечает только сцены, которым такой кадр
     действительно подходит, и не больше заданной доли. Недобор достаётся нейрогенерации.
     Если нейрогенерации 0 % или картинки и видео стоят на «Пропустить», нейросети не
     используются вовсе: оставшиеся сцены режиссёр вторым запросом раскладывает по включённым
     источникам — по тому, что подходит сцене, а доли лишь подсказывают выбор между равными.
     Сцене, которой не подходит ничего, достаётся кадр соседнего клипа («удержание»); сцену,
     которую сток не закрыл, программа ищет ещё раз (без строгого отбора), а в крайнем случае
     тоже ставит кадр соседа;
   - *Рендер и склейка* — качество, битрейт, FPS, переходы, зум, логотип, субтитры.
5. **«▶ Запустить конвейер».** Прогресс виден в журнале и в таблице. Готовые проекты уходят в фоновую
   очередь склейки, и конвейер сразу берёт следующий файл.
6. **Изменения на ходу.** Настройки можно менять во время работы — они применяются к файлу, который идёт
   сейчас, через пару секунд после последнего изменения (журнал пишет, что изменилось и что с этим делается):
   - провайдеры, модели, потоки, режимы и прочее, что влияет на генерацию, — генерация перезапускается с места:
     процесс останавливается, задачи в работе снимаются, и тот же проект продолжается с новыми настройками
     (готовые картинки и видео не пересоздаются). Пришлось на режиссуру — план дописывается, и генерация сразу
     начинается с новыми настройками;
   - параметры склейки (качество, переходы, логотип, субтитры…) — склейка этого файла пойдёт с ними, если ещё
     не началась; перезапуска нет;
   - настройки режиссуры после готового плана действуют со следующего файла.
   Файлы со «★ своими настройками» или пресетом изменения формы не трогают.

Результаты лежат в `projects/<имя файла>/`, итоговое видео — `projects/<имя>/<имя>.mp4`.

## 6. Панель управления

Ручной режим для отдельных проектов:

- **Проекты.** Таблица со статусом каждого проекта: есть ли аудио, расшифровка, план, сколько картинок и видео, собран ли MP4.
  Сортировка по клику на заголовок, поиск, двойной клик открывает папку, правый клик — меню действий.
- **Отдельные стадии.** Расшифровка, Режиссура, Картинки, Видео, Склейка.
  Окна параметров нет: стадия запускается сразу, с ПОСЛЕДНИМИ настройками вкладки «Конвейер»
  (расшифровка спросит только файл). Стайлгайд режиссуры — выбранный в «Конвейере» (один на все), иначе
  копия, с которой проект создавался. «Картинки» рисуют и инфографику — провайдером и моделью из блока
  «Инфографика». «Видео» берёт файл общего промпта из формы и адаптирует промпты под видео, если это
  включено. Склейка с «без лого» не накладывает logo.png, оставшийся в проекте.
- **Довести проект.** Одна кнопка: выделенный проект продолжается с того места, где остановился, по последним
  настройкам «Конвейера» и тем же маршрутом, что у конвейера. Нет монтажного плана — режиссура; у какого-то
  клипа нет материала (сток, инфографика, моушн-графика, обложка, картинка или видео нейрокадра) — генерация:
  источники кадра, картинки, видео и добор пустых сцен, как в конвейере; всё готово, но нет MP4 — только
  склейка. Если ролик уже собран, программа так и скажет. Готовое не пересоздаётся. Тот же пункт есть в меню
  правой кнопки мыши по проекту.
- **Готовые и битые файлы.** Картинки и видео записываются целиком или никак: прерванная запись («Стоп»,
  сбой) не оставляет обрезанного файла. Файлы, оборванные раньше, «Картинки», «Видео», «Склейка» и «Довести
  проект» находят перед работой и откладывают как `*.broken` — такой клип делается заново. Повторная
  «Режиссура» проекта, где уже есть кадры, спрашивает подтверждение и переносит картинки, видео, старый план,
  промпты и собранный ролик в папку проекта `old_<дата>/` — иначе новые сцены получили бы кадры старых
  («Довести проект» с повреждённым планом делает это сам). Ничего не удаляется.
- **Очередь склейки.** Склейки идут строго по одной и не мешают генерации. Текущую склейку можно отменить.
- **Стоп / Перезапуск ключа.** «Стоп» (он же есть в «Конвейере») сразу завершает процессы вместе с дочерними
  (Codex, рендер Remotion, генерация) и снимает серверные задачи: FastGen и VeoNonStop — на всех ключах,
  VARAG — все активные задачи ключа (в том числе запущенные с других компьютеров этим же ключом),
  RoyalTechno — задачи, запущенные программой. У Vertex, CheapVibeCode и CinAI отмены в API нет: их запросы
  обрываются вместе с процессом. «Стоп» в «Панели» работает и когда ничего не запущено — снимает зависшие
  задачи на сервере. Закрытие программы с идущими задачами делает то же самое. Очередь склейки «Стоп» не
  трогает — текущую склейку отменяют в её карточке. «Перезапуск ключа» снимает зависшие задачи VeoNonStop,
  не останавливая генерацию.

Журнал каждой стадии сохраняется в папке проекта (`stage_*.log`, `pipeline_full.log`).

## 7. Промпты

Все инструкции для ИИ и шаблоны субтитров `.ass` разложены по группам: режиссура, генерация, сток,
субтитры.

- Поиск идёт по названиям и внутри текстов, Ctrl+F ищет в открытом файле.
- Ctrl+S сохраняет файл. При переходе на другой файл программа предложит сохранить правки.
- «Заводской вариант» возвращает исходный текст, а текущий сохраняет рядом как `.bak`.
  Заводские копии хранятся в `engine/instructions_default/`.
- Свои `.txt`/`.md` файлы, добавленные в `engine/instructions/`, появятся в группе «Дополнительные».

## 8. Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+1 … Ctrl+4 | Конвейер / Панель управления / Промпты / Настройки |
| Ctrl+S | Сохранить (Настройки, Промпты) |
| Ctrl+F | Поиск в тексте промпта |

## 9. Структура папок

```
BegoFrame/
├── bego.py              точка входа
├── start.bat / setup.bat
├── requirements.txt     зависимости Python
├── studio/              интерфейс (PySide6)
│   ├── pages/           вкладки: конвейер, панель, промпты, настройки
│   ├── pipeline/        описание разделов конвейера и сборка запуска
│   ├── services/        мониторы квот, очередь склейки, процессы, пресеты
│   └── ui/              виджеты, построитель форм, диалоги
├── engine/              движок: расшифровка, режиссура, генерация, склейка
│   ├── cli.py           командная строка движка
│   ├── stage_runner.py  запуск одной стадии (Панель управления)
│   ├── finish_runner.py доводка проекта
│   ├── assemble.py      склейка видео
│   ├── units/           модули сервисов
│   ├── instructions/    промпты (правятся во вкладке «Промпты»)
│   ├── templates/       шаблоны субтитров
│   └── .env             ваши ключи и параметры (создаётся автоматически)
├── projects/            проекты
├── inbox/               входящие файлы очереди
├── runtime/             Codex CLI, временные файлы
└── userdata/            пресеты, состояние окна, журналы
```

## 10. Если что-то не работает

- **«GPT: нет входа».** Войдите в Codex в «Настройках». Если вход не проходит, проверьте прокси кнопкой «Проверить».
- **Склейка не запускается.** Проверьте, что `ffmpeg -version` работает в командной строке.
- **Журналы.** Журнал интерфейса лежит в `userdata/logs/studio.log`, журналы стадий — в папке проекта.
  Кнопка «📜 Журналы» слева открывает папку.
- **Смена языка или темы** пересобирает окно, поэтому она недоступна, пока идут задачи.

## 11. Выпуск новой версии (для разработчика)

1. Поднять `APP_VERSION` в `studio/__init__.py`, описать изменения в `CHANGELOG.md` (раздел `## <версия>`).
2. `python tools/build.py` — в `dist/<версия>/` появятся установщик, zip-обновление и `latest.json`
   (нужны Inno Setup: `winget install JRSoftware.InnoSetup`, и интернет при первой сборке среды Python).
3. `python tools/release.py publish` — исходники уходят в [Begov/updates](https://github.com/Begov/updates),
   создаётся Release `v<версия>` с файлами. Установленные программы увидят его при следующем запуске.

Если не менялись `requirements.txt` и версия Python в `tools/build.py`, пользователи получат маленький
zip с кодом (несколько МБ), иначе — полный установщик (~50 МБ).

## 12. Шрифт

Интерфейс использует шрифт Inter (лицензия SIL OFL, файлы лежат в `studio/assets/fonts/`).
Если папка со шрифтами удалена, программа автоматически перейдёт на системный Segoe UI.
