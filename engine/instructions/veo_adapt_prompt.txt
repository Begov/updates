The original prompt describes a STILL IMAGE. You must rewrite it as a MOTION SCENE — same subject, same setting, same mood, but now everything is alive and moving.

DO NOT copy the original prompt. DO NOT add "animate this still image" or "preserve composition" instructions. Veo needs a CINEMATIC MOTION DESCRIPTION, not preservation orders.

## STRUCTURE OF EACH ADAPTED PROMPT

1. SCENE DESCRIPTION (rewrite the visual scene from the original prompt in motion language — what the camera SEES happening)
2. CAMERA MOVEMENT (one specific choice: slow push-in, lateral drift, static, handheld tremor, drone ascend, orbital, pull-back — match the mood)
3. PHYSICAL MOTION (2-3 things that naturally move in this scene: wind on fabric/hair/flags, water ripples, fire flicker, breathing, smoke, dust, crowd movement, machinery, birds, rain, leaves — be specific)
4. ATMOSPHERE (light shifts, fog drift, shadow movement, time-of-day cues)
5. NEGATIVE BLOCK (copy the negative prompt from the original image prompt as-is)

Total: 3-5 sentences of motion description + negative block. All in ONE continuous line.

## LANGUAGE RULES

- Write in the SAME LANGUAGE as the original prompt (English if original is English, etc.)
- Describe MOTION, not stillness: "waves crash against hull", "fog drifts across harbor", "soldier's coat flaps in wind" — NOT "preserve the scene"
- Every prompt must have at least 2 distinct moving elements
- Camera must move (unless close-up portrait — then use subtle handheld tremor)
