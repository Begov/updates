# ============================================================================

# Эти слова дописываются к КАЖДОМУ запросу к Яндекс-Картинкам как исключения
# (Яндекс понимает `-слово` как активное исключение из выдачи). Нужны потому,
# что общий/generic-запрос («деньги», «солдаты») тянет из веба много мусора.
#
# Правила файла:
#   • строки, начинающиеся с #, и пустые — игнорируются (это комментарии);
#   • всё остальное объединяется в один суффикс через пробел;
#   • можно писать флаги в несколько строк — они склеятся.
#
# ВАЖНО: Яндекс оставляем ТОЛЬКО под реальные фото. Живопись/гравюры/иллюстрации
# эпохи приходят из Wikipedia/архивов, поэтому у Яндекса их ЧИСТИМ (см. -рисунок
# -арт -гравюра -картина ниже). Не добавляй сюда то, что бывает уместно из архивов.
#
# Осторожно: Яндекс трактует минус жёстко — слишком много флагов может подрезать
# и нужное. Если выдача пустеет — убери часть строк.
#
# (Полностью переопределяется через env REAL_PHOTO_YANDEX_EXCLUDE, если задан.)
# ============================================================================
