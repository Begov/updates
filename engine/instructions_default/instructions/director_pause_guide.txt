# 🎬 РЕЖИССЁРАМ: ОБРАБОТКА ПАУЗ В МОНТАЖНОМ ПЛАНЕ

## ⚠️  КРИТИЧЕСКИ ВАЖНОЕ ПРАВИЛО

**AssemblyAI транскрибирует ТОЛЬКО РЕЧЬ. Паузы не транскрибируются!**

Твоя задача: **правильно обработать паузы** 

---

## 📊 ТИПЫ ПАУЗ И ИХ ОБРАБОТКА

| Длительность | Тип | Решение |
|--------------|-----|---------|
| < 0.5 сек | Техническая | Игнорируй |
| 0.5 - 4.0 сек | Короткая | Включи в endTime предыдущей сцены |
| > 4.0 сек | Длинная | **СОЗДАЙ БОНУСНЫЙ CLIP!** |

---

## 🎯 ПАУЗА > 4.0 СЕКУНД — БОНУСНЫЙ CLIP

**ПРОБЛЕМА:**
Если пауза 7 секунд и ты добавишь её к предыдущей сцене (3с речи + 7с паузы = 10с),
зритель будет смотреть на **один кадр 10 секунд** — это скучно!

**РЕШЕНИЕ:**
Создай **бонусный clip** с другим ракурсом!

---

## 📋 ПРИМЕРЫ

### Пример 1: Короткая пауза (2.0 сек)

**Транскрипция:**
```
Фраза 1: [0.00 - 5.00] "Привет, я вернулся."
Фраза 2: [7.00 - 10.00] "Сегодня поговорим о..."
Пауза: 2.0 сек
```

**Montage Plan:**
```json
{
  "clips": [
    {"id": 1, "startTime": 0.00, "endTime": 7.00},
    {"id": 2, "startTime": 7.00, "endTime": 10.00}
  ]
}
```

**Обоснование:**
> Clip 1: 7.0с = 5.0с речи + 2.0с паузы. Короткая пауза, зритель не заскучает.

---

### Пример 2: Длинная пауза (7.0 сек) — БОНУСНЫЙ CLIP!

**Транскрипция:**
```
Фраза 1: [10.00 - 13.00] "И вдруг... раздался грохот."
Фраза 2: [20.00 - 25.00] "Это упала книга."
Пауза: 7.0 секунд!
```

**❌ НЕПРАВИЛЬНО:**
```json
{
  "clips": [
    {"id": 1, "startTime": 10.00, "endTime": 20.00},
    {"id": 2, "startTime": 20.00, "endTime": 25.00}
  ]
}
```
> Clip 1 длится 10.0с (3.0с речи + 7.0с паузы) — зритель устанет ждать!

**✅ ПРАВИЛЬНО:**
```json
{
  "clips": [
    {"id": 1, "startTime": 10.00, "endTime": 13.00},
    {"id": 2, "startTime": 13.00, "endTime": 20.00},
    {"id": 3, "startTime": 20.00, "endTime": 25.00}
  ]
}
```

**Обоснование:**
> Clip 1 (id=1): 3.0с — основная сцена (речь)
>
> Clip 2 (id=2, бонусный): 7.0с — **другой ракурс той же сцены!**
> - Например: крупный план детали, реакция персонажа, общий план
> - Сохраняет визуальный интерес во время паузы
> - YouTube-динамика: смена кадра каждые 3-5 сек
> - ⚠️ БОНУСНЫЙ КЛИП ПОЛУЧАЕТ СЛЕДУЮЩИЙ ПОРЯДКОВЫЙ ID (id=2, не id=1!)

**⚠️ КРИТИЧЕСКИ ВАЖНО ПРО ID:**
Каждый клип (включая бонусные) получает **уникальный последовательный id**.
**НИКОГДА** не используй одинаковый id для основного и бонусного клипа!

---

### Пример 3: Очень длинная пауза (15.0 сек)

**Транскрипция:**
```
Фраза 1: [0.00 - 5.00] "Начинаем..."
Фраза 2: [20.00 - 25.00] "Продолжаем..."
Пауза: 15.0 секунд!
```

**✅ ПРАВИЛЬНО (2 бонусных клипа):**
```json
{
  "clips": [
    {"id": 1, "startTime": 0.00, "endTime": 5.00},
    {"id": 2, "startTime": 5.00, "endTime": 12.00},
    {"id": 3, "startTime": 12.00, "endTime": 20.00},
    {"id": 4, "startTime": 20.00, "endTime": 25.00}
  ]
}
```

**Обоснование:**
> Clip 1 (id=1): 5.0с — основная сцена
>
> Clip 2 (id=2, бонусный): 7.0с — бонусный ракурс #1 (например, средний план)
>
> Clip 3 (id=3, бонусный): 8.0с — бонусный ракурс #2 (например, крупный план детали)
>
> Clip 4 (id=4): следующая речь
>
> -> Три разных кадра за 15 секунд паузы = динамика!
> -> ID строго последовательны: 1, 2, 3, 4 — без повторов!

---

## ⚠️ ПРАВИЛО НУМЕРАЦИИ ID — ОБЯЗАТЕЛЬНО

**Каждый клип (включая бонусные) получает УНИКАЛЬНЫЙ последовательный id.**

```
Речь [0-5с]     -> id=1
Бонус [5-12с]   -> id=2  (НЕ id=1!)
Бонус [12-20с]  -> id=3  (НЕ id=1!)
Речь [20-25с]   -> id=4  (НЕ id=2!)
```

**❌ ЗАПРЕЩЕНО:** использовать одинаковый id для основного и бонусного клипа.
**✅ ПРАВИЛО:** id = просто порядковый номер клипа в общем списке, 1..N без пропусков.

## ⚡ КОРОТКИЕ СЕГМЕНТЫ ТРАНСКРИПЦИИ (< 4 сек)

**Проблема:** Некоторые фразы в транскрипции физически занимают 1-2 секунды.
Нельзя создавать клип < 4 секунд — это нарушение!

**Решение: объединяй короткий сегмент с соседом**

| Ситуация | Решение |
|----------|---------|
| Фраза < 4с, следующая пауза < 0.5с | Включи следующую фразу в тот же клип |
| Фраза < 4с, следующая пауза 0.5-4с | Включи паузу + следующую фразу в тот же клип |
| Фраза < 4с, следующая пауза > 4с | Расширь endTime до min 4.0с (съешь часть паузы) |

**Пример:**
```
Фраза 1: [5.00 - 7.80] "Хорошая мысль."
Фраза 2: [8.20 - 9.90] "Шок!"    ← 1.7 сек — СЛИШКОМ КОРОТКО
Фраза 3: [10.40 - 14.00] "Продолжение..."
```

❌ НЕПРАВИЛЬНО:
```json
{"id": 2, "startTime": 8.20, "endTime": 9.90}   ← 1.7 сек!
```

✅ ПРАВИЛЬНО — объединить с соседом:
```json
{"id": 2, "startTime": 8.20, "endTime": 12.20}  ← 4.0 сек ✓ (пауза + начало фразы 3)
```

**Главное правило: эндтайм клипа должен быть не менее startTime + 4.0 секунды.**

---

## 🎥 ИДЕИ ДЛЯ БОНУСНЫХ КАДРОВ

**Для одной сцены создай несколько ракурсов:**

1. **Общий план** (Wide shot) — установочный кадр
2. **Средний план** (Medium shot) — действие персонажа
3. **Крупный план** (Close-up) — эмоция, деталь
4. **Деталь** (Insert shot) — объект, рука, глаз

**Пример для сцены "Кот на кровати":**
- Clip 1: Средний план — кот прыгает на кровать
- Clip 1b: Крупный план — морда кота, мурчание
- Clip 1c: Общий план — кот устроился на кровати

## 📏 АЛГОРИТМ ОБРАБОТКИ ПАУЗ

### ШАГ 1: Найди паузы

```python
for i in range(len(transcription) - 1):
    gap = transcription[i+1]['start'] - transcription[i]['end']
    
    if gap < 0.5:
        # Игнорируй (техническая пауза)
    elif gap <= 4.0:
        # Включи в endTime предыдущей сцены
    else:
        # СОЗДАЙ БОНУСНЫЙ CLIP!
```

### ШАГ 2: Реши сколько бонусных клипов нужно

```
Пауза 4-8 сек   -> 1 бонусный клип
Пауза 8-15 сек  -> 2 бонусных клипа
Пауза > 15 сек  -> 3+ бонусных клипа
```

### ШАГ 3: Опиши визуал для бонусных клипов

Для каждого бонусного клипа:
- **Новый ракурс** (не повторяй предыдущий!)
- **Деталь или реакция** (что зритель должен заметить)
- **Атмосфера паузы** (напряжение, ожидание, созерцание)

---

## ⚠️  ОГРАНИЧЕНИЕ ДЛИТЕЛЬНОСТИ СЦЕН

**Правило 4-12 секунд:**

| Тип сцены | Длительность | Когда использовать |
|-----------|--------------|-------------------|
| Короткая | 4-5 сек | Реплика, акцент, быстрое действие |
| Средняя | 5-8 сек | Основное повествование, диалог |
| Длинная | 8-12 сек | Созерцание, атмосфера, кульминация |

**❌ НЕ создавай сцены:**
- < 4 секунд — зритель не успеет рассмотреть
- > 12 секунд — зритель заскучает

**Если нужна длительность > 12 сек:**
- Разбей на 2 сцены с разными ракурсами
- Используй бонусные клипы для пауз > 4 сек

---

## 📋 ЧЕК-ЛИСТ ПЕРЕД СОХРАНЕНИЕМ

□ clips[0].startTime = 0.00 (покрывает начало)
□ clips[last].endTime = audioDuration (покрывает конец)
□ Между clips нет гэпов > 0.1 сек
□ Паузы 0.5-4.0 сек включены в endTime предыдущей сцены
□ Паузы > 4.0 сек разбиты на бонусные клипы
□ Бонусные клипы имеют **новый ракурс/деталь**
□ **Длительность каждой сцены: 4-12 секунд**
□ **НЕТ клипов короче 4 секунд** (короткие сегменты объединены с соседями)
□ **ID строго последовательны 1..N** (бонусные клипы тоже получают свой уникальный id)
□ **НЕТ повторяющихся id** (каждый клип — уникальный номер)
□ JSON валидный

## 💡 YOUTUBE-ДИНАМИКА (РЕКОМЕНДАЦИЯ)

**Правило 5-8 секунд:**

Зритель YouTube привык к быстрой смене кадров:
- 4-5 сек — короткий клип (реплика, действие)
- 5-8 сек — средний клип (описание, атмосфера)
- 8-10 сек — длинный клип (созерцание, кульминация)
- **> 10 сек — скучно!** (разбей на бонусные клипы)

**Используй бонусные клипы для пауз:**
- Пауза 7 сек = 1 бонусный клип (7 сек)
- Пауза 12 сек = 2 клипа (5 сек + 7 сек)
- Пауза 20 сек = 3 клипа (6 сек + 7 сек + 7 сек)
