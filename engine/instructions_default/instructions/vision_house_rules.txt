# ЗАПРЕТЫ ДЛЯ ОТБОРА ГОТОВЫХ КАДРОВ
#
# Здесь перечисляется то, чего НЕ ДОЛЖНО БЫТЬ в кадре. Список читает
# вижн-модель, которая выбирает кадры из стоков, архивов и ютуба: кадр с
# запрещённым уходит в брак, даже если по сюжету он подходит идеально.
#
# КАК ПИСАТЬ
#   * по одному предмету на строку;
#   * коротко и предметно — что должно быть видно в кадре, чтобы забраковать;
#   * НА АНГЛИЙСКОМ: задание вижну целиком английское, и русская строка среди
#     него читается слабее;
#   * не указания «не выбирай такое», а просто перечень: alcohol, cigarettes;
#   * строки, начинающиеся с #, — комментарии, в работу не идут.
#
# ПУСТОЙ ФАЙЛ НИЧЕГО НЕ МЕНЯЕТ. Пока здесь нет ни одной строки, отбор работает
# ровно так же, как работал.
#
# НА НЕЙРОГЕНЕРАЦИЮ ЭТО НЕ ДЕЙСТВУЕТ — там кадр рисуется с нуля, и запреты
# задаются негатив-промптом в стайлгайде.
#
# ПРИМЕРЫ — снимите # с нужной строки или впишите своё ниже:
#
# woman with uncovered hair
# alcohol, alcoholic drinks, beer, wine bottles
# cigarettes, smoking, vaping
# pork, ham, bacon
# gambling, casino, playing cards
# visible tattoos
#
# ─────────────────────────────────────────────────────────────────────────────
# Ниже можно разложить запреты по стадиям. Строки ДО первой пометки в
# квадратных скобках действуют на все стадии сразу — обычно этого и достаточно.
#
#   [all]        — на все стадии (то же, что писать в самом верху)
#   [stock]      — только сток: Pexels, Pixabay, Envato
#   [real_photo] — только архивы: Wikipedia, NASA, музеи, поиск Google
#   [youtube]    — только ютуб-футаж
#
# Пример:
#   [stock]
#   studio background
#
# ─────────────────────────────────────────────────────────────────────────────
